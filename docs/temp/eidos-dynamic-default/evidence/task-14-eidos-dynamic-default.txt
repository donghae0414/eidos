Implementation
--------------
Step panel synchronizes active/completed steps with the rolling-update diagram.
Exploded view separates and reassembles Docker image layers with leader lines and focus.
Chart morph preserves 100 stable cell IDs through bars, share strip, and waffle layouts.
Bar race interpolates timestamped values, sorts ties by string ID, fixes a zero-inclusive
domain across the dataset, and displays top K. Missing own values become zero, including
IDs such as constructor and __proto__. Duplicate timestamps retain the first row and
report a descriptive error. Numeric options and own easing names are validated.

Pinned scrollytelling leaves an inert layout slot and reparents the real figure next
to world, outside its transform. onLayout measures the slot and scroll anchors.
Strictly increasing y/time pairs define a clamped piecewise-linear map and inverse.
Programmatic scroll feedback is suppressed; reader scroll seeks the shared timeline.
data-eidos-noclick participates in the existing runtime gesture ownership mechanism,
so the column owns wheel/swipe even at its edges. No runtime hook was necessary.
Reduced mode retains the figure in document flow and disables scroll-to-time coupling.
The card explicitly notes that runtime snapshot() excludes the external figure;
the semantic probe adds its real outerHTML to the signature and checks camera isolation.

Every zero-duration authored track retains its source at t === start and changes
only for t > start. Positive endpoints use the runtime's snapped progress.
Reduced mode uses discrete checkpoints rather than continuous movement.
Initial assembled part opacity is explicitly 1. Reassembly captures the cache
labels before the simultaneous focus reset, preserving the parked cache state.
