# 토큰 쪼개기 (Token Split)

**장면 관계:** 한 장면 안에서 문장 하나가 모델이 읽는 단위로 바뀌는 순간을 보여 줄 때 씁니다. 장면 경계의 `via` 값이 아니므로 `s.fx`로 부릅니다.

## 전달하는 의미
**모델은 이 문장을 이 조각들로 읽는다.** 붙어 있던 문장이 간격을 두고 조각으로 벌어지고, 조각마다 색과 번호가 붙습니다. 사람이 읽는 단어와 모델이 읽는 토큰이 다르다는 것, 토큰마다 어휘 사전의 번호(ID)가 있다는 것을 한 동작으로 보여 줍니다.

조각 경계와 번호는 **설명용 예시**입니다. 실제 토크나이저(tiktoken, SentencePiece 등)로 뽑은 값을 넘긴 것이 아니라면 화면이나 캡션에 예시라고 밝히세요. 같은 문장도 토크나이저마다 조각과 번호가 다릅니다.

## 언제 쓰나
- 토큰화를 처음 소개할 때 ("모델은 글자가 아니라 토큰을 읽는다")
- 같은 뜻의 문장이 언어나 표기에 따라 토큰 수가 달라지는 것을 비교할 때 (API 요금, 컨텍스트 사용량)
- attention-lines, next-token 앞에서 입력 문장을 처리 단위로 펼쳐 둘 때

## 피할 때
- 조각과 번호를 실제 토크나이저 결과처럼 단정할 때. 확인한 값이 아니면 예시라고 적습니다
- 문단 전체. 한 문장, 조각 3~12개가 읽기 좋습니다
- 조각을 흩뜨리거나 순서를 섞을 때. 토큰 순서가 곧 의미이므로 순서와 줄은 그대로 둡니다
- 단어 강세와 낭독 리듬(kinetic-type), 글자가 하나씩 만들어지는 느낌(text-scramble)

## 사용법
```html
<p class="sentence" id="ko">캐시가 시간을 아낀다</p>
```
```js
s.fx("token-split", {
  targets: "#ko",
  tokens: ["캐시", "가", " 시간", "을", " 아", "낀다"],  // 이어 붙이면 원문과 같아야 합니다
  ids: [41820, 7653, 10423, 5012, 9147, 30561],         // 선택: 조각 아래 번호
});
s.tl.stop("같은 뜻의 한국어 문장은 토큰 6개입니다");
```
**조각 만들기.** 기법이 대상 요소의 글자를 `tokens` 경계대로 잘라 조각마다 `span.eidos-token`(inline-block)을 만듭니다. `tokens.join("")`은 대상의 `textContent`와 공백까지 정확히 같아야 하며, 다르면 어느 글자에서 어긋났는지 오류로 알립니다. 연속 공백과 앞뒤 공백은 그대로 보존합니다. 토큰 앞뒤 공백은 조각 밖의 띄어쓰기로 그립니다(실제 토크나이저는 공백을 다음 토큰 앞에 붙이는 경우가 많습니다). 공백 없이 이어진 조각들은 줄바꿈 금지 단위(`span.eidos-token-word`)로 묶으므로 한국어 어절이 줄 끝에서 갈라지지 않습니다. 대상 안에는 글자만 둡니다(`<b>` 같은 자식 요소가 있으면 오류).

조각의 `transform`, 배경색, 테두리 그림자와 번호의 `opacity`, `transform`은 이 기법이 씁니다. 글자 크기, 굵기, 정렬은 대상의 CSS를 따르고, 붙은 상태는 `text-align`(왼쪽, 가운데, 오른쪽)에 맞춰 계산합니다. 번호를 쓰면 조각 아래에 번호 자리를 미리 비워 두므로 여러 줄 문장은 줄 간격이 넓어집니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `targets` | (필수) | 문장 요소 하나. 안에는 글자만 둡니다 |
| `tokens` | (필수) | 조각 문자열 배열. `tokens.join("")`이 대상 글자와 같아야 합니다 |
| `ids` | 없음 | 조각 아래에 보일 번호 배열(숫자나 문자열). `tokens`와 길이가 같아야 합니다 |
| `gap` | `8` | 벌어진 조각 사이에 더하는 간격(px) |
| `dur` | `0.6` | 조각이 벌어지는 시간(초). 모든 조각이 함께 움직여 간격이 줄지 않고 넓어지기만 합니다 |
| `each` | `0.04` | 조각마다 색과 번호가 붙는 시작 간격(초). 왼쪽 조각부터 읽는 순서대로 붙습니다 |
| `at` | 이어서 | 시작 시각 |

반환값: `{ start, end, items: [{ el, token, id, start, end }] }`. `el`은 조각 span이고, 조각의 `start`와 `end`는 그 조각에 색과 번호가 붙는 구간입니다. 조각 색은 `--eidos-cat-1`부터 다섯 가지를 차례로 돌려 씁니다.

## 변형
- **번호 없이:** `ids`를 빼면 조각과 색만 보입니다. 경계 자체가 주제일 때
- **두 문장 비교:** 같은 뜻의 문장 두 개를 stop마다 하나씩 쪼개 토큰 수를 비교합니다(템플릿)
- **하나씩 세기:** `each: 0.12`면 색과 번호가 하나씩 붙어 개수를 세는 박자가 됩니다
- **넓게 벌리기:** 발표 화면처럼 글자가 클 때는 `gap: 16`. 너무 벌리면 한 문장으로 읽히지 않습니다

## reduced-motion
조각이 미끄러지지 않습니다. 진행의 절반에서 붙은 문장이 나뉜 상태(색과 번호 포함)로 한 번에 바뀌고 중간 프레임은 없습니다. 런타임이 stop 사이를 즉시 건너뛰고 200ms 페이드로 보여 주므로, 보통은 붙은 문장과 나뉜 결과만 보입니다. 블러와 3D는 쓰지 않습니다.

## 같이 쓰기 좋은 기법
attention-lines(나뉜 토큰 사이의 참조를 이어서), next-token(나뉜 입력 뒤에 다음 토큰을 고르는 장면), highlight-sweep(토큰 하나를 짚을 때), count-up(토큰 수나 요금을 숫자로 보일 때)
