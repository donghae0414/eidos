# 어텐션 선 (Attention Lines)

**장면 관계:** 한 장면 안에서 토큰 한 줄을 두고 "이 토큰이 다른 토큰을 얼마씩 보는가"를 그릴 때 씁니다. 장면 경계의 `via` 값이 아니므로 `s.fx`로 부릅니다.

## 전달하는 의미
**이 토큰은 저 토큰들을 이만큼씩 본다.** 질의 토큰에서 다른 토큰으로 호가 그려지고, 선 굵기와 진하기가 어텐션 가중치를 나타냅니다. 호가 다 그려지면 가중치가 가장 큰 토큰이 강조색으로 남아 "모델이 지금 이 토큰에 기대고 있다"는 결론이 됩니다. 멀리 떨어진 토큰도 가까운 토큰과 똑같이 한 번에 이어지므로, 어텐션이 거리와 상관없이 관련 있는 토큰을 찾는다는 점이 함께 보입니다.

## 언제 쓰나
- 셀프 어텐션이나 어텐션 가중치를 처음 설명할 때
- 지시어가 멀리 떨어진 명사를 가리키는 것처럼, 관련 있는 토큰에 비중이 몰리는 모습을 보여 줄 때
- 질의 토큰을 바꿔 가며 토큰마다 보는 곳이 다르다는 것을 비교할 때 (`from`만 바꿔 다시 부름)

## 피할 때
- 가중치가 모두 비슷할 때. 굵기 차이가 사라지면 선이 아무 말도 하지 않습니다. 차이가 분명한 예를 고르세요
- 토큰이 10개를 넘거나 한 줄에 들어가지 않을 때. 호가 겹치고, 줄이 바뀌면 호가 글자를 가로지릅니다. 문장을 줄이세요
- 예시 숫자를 실제 모델의 측정값처럼 보이게 할 때. 실제 값이 아니면 화면에 "예시"라고 적습니다
- 문장을 토큰으로 나누는 과정 자체(token-split)나 다음 토큰의 확률(next-token)을 보여 줄 때

## 사용법
```html
<div class="row">
  <span class="tok">캐시가</span><span class="tok">가득</span><span class="tok">차서</span>
  <span class="tok">로그를</span><span class="tok">보고</span><span class="tok">그것을</span>
</div>
```
```js
s.fx("attention-lines", { targets: ".tok", from: 4, weights: [0.10, 0.05, 0.12, 0.55, 0.18, 0] });
s.tl.stop("'보고'는 바로 앞 목적어 '로그를'을 가장 많이 봅니다");
s.fx("attention-lines", { targets: ".tok", from: 5, weights: [0.46, 0.07, 0.11, 0.22, 0.04, 0.10] }); // 질의 바꾸기
s.tl.stop("'그것을'은 멀리 떨어진 '캐시가'에 가장 큰 비중을 둡니다");
```
**가중치 읽기.** `weights`는 어텐션 행렬에서 질의 토큰의 한 행입니다. 토큰마다 하나씩, 토큰 순서대로 넣습니다. `from` 자리의 값은 자기 자신 몫이라 선을 그리지 않고, 0인 토큰(인과 마스크로 가려진 뒤 토큰 등)에는 선도 숫자도 없습니다. 선 굵기와 진하기는 그려지는 토큰 중 가장 큰 가중치를 기준으로 비례하고, 숫자는 소수 둘째 자리까지 토큰 아래에 붙습니다.

**그려지는 자리.** 기법이 토큰들의 가장 가까운 공통 부모(위 예시의 `.row`) 안에 SVG(`.eidos-attention`)를 붙이고, `onLayout`에서 토큰 위치를 재서 호를 그립니다. 그래서 호가 토큰과 함께 장면 전환과 카메라를 따라갑니다. 부모가 `position: static`이면 `relative`로 바꿉니다. 호는 토큰 위로 두 토큰 거리의 약 0.3배만큼 솟으므로 줄 위에 그만큼, 줄 아래에는 숫자 한 줄만큼 자리를 비워 두세요. 부모에 `overflow: hidden`이 있으면 호가 잘립니다. 위치는 토큰의 레이아웃 자리(transform 전)를 쓰므로, 선이 보이는 동안 토큰을 transform으로 옮기지 않습니다.

**질의 바꾸기.** 같은 토큰에 다시 부르면 이전 호와 숫자, 테두리가 0.3초 동안 물러나고 새 질의의 호가 그려집니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `targets` | (필수) | 토큰 요소들. 2개 이상이고 요소 순서가 토큰 순서입니다 |
| `weights` | (필수) | 토큰마다 하나인 0 이상의 숫자 배열. 길이가 토큰 수와 다르면 오류입니다 |
| `from` | 마지막 토큰 | 질의 토큰 번호(0부터). 테두리가 생기고 호가 여기서 출발합니다 |
| `labels` | `true` | 호가 닿는 토큰 아래에 가중치 숫자를 붙일지 |
| `dur` | `0.9` | 호 하나를 그리는 시간(초) |
| `each` | `0.12` | 호 사이 시차(초). 토큰 순서대로 그립니다 |
| `at` | 이어서 | 시작 시각 |

반환값: `{ start, end, items: [{ el, index, weight, top, path, label, start, end }] }`. `items`는 호를 그린 토큰마다 하나이고, `top`은 가장 큰 가중치를 받아 강조된 토큰입니다(동점이면 모두).

## 변형
- **질의 바꾸기:** 같은 줄에 `from`만 바꿔 다시 부르면 토큰마다 보는 곳이 다르다는 비교가 됩니다
- **인과 마스크:** 질의 뒤 토큰의 가중치를 0으로 두면 뒤쪽에는 선이 없어 "앞 토큰만 본다"가 드러납니다
- **숫자 없이:** 발표처럼 굵기 비교만 보여 줄 때는 `labels: false`
- **하나씩 짚기:** `each: 0.35`로 늘리면 호가 차례로 그려져 가중치를 하나씩 읽을 시간이 생깁니다

## reduced-motion
호가 그려지는 대신 완성된 호의 불투명도만 0에서 가중치 진하기로 바뀝니다. 숫자는 이동 없이 나타납니다. 가장 큰 가중치의 호와 숫자는 처음부터 고정된 강조색을 쓰고, 마지막에 토큰 테두리가 불투명도로 나타납니다. 색이나 위치는 보간하지 않습니다. 런타임이 stop 사이를 즉시 건너뛰므로 보통은 완성된 그림만 보입니다. 블러와 3D는 쓰지 않습니다.

## 같이 쓰기 좋은 기법
token-split(문장을 토큰으로 나눈 뒤 이어서 어텐션), next-token(가장 많이 본 토큰을 근거로 다음 토큰을 고를 때), highlight-sweep(강조된 토큰을 본문 설명에서 다시 짚기)
