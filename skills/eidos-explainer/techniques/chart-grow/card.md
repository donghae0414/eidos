# 차트 성장 (Chart Grow)

## 전달하는 의미
**값이 쌓여 추세가 된다.** 막대는 0 기준선에서 자라고, 선은 시간 순서대로 그려져 범주 사이의 크기와 변화 방향을 드러냅니다.

## 언제 쓰나
- 월별 배포 횟수처럼 양을 비교할 때는 막대
- 장애 건수처럼 시간에 따른 흐름을 읽을 때는 선
- 결과를 한 번에 나열하기보다 순서대로 읽게 할 때

## 피할 때
- 음수, 누적 계열, 불규칙 시간 간격. 이 기법은 음이 아닌 단일 계열과 등간격 범주용입니다
- 범주가 너무 많아 라벨을 읽기 어려울 때. 먼저 집계하세요
- 서로 다른 차트의 축 범위를 숨긴 채 높이만 비교할 때

## 사용법
```html
<div id="deploy"></div>
```
```js
const chart = stage.fx("chart-grow", {
  el: "#deploy", kind: "bar",
  categories: ["1월", "2월", "3월"],
  values: [12, 18, 24], max: 30, unit: "회",
});
stage.tl.stop("배포 횟수가 매달 늘었습니다");
```
빌드 시 축·격자·범주·수치 라벨을 포함하는 인라인 SVG를 만듭니다. `viewBox`와 `preserveAspectRatio`로 비율을 유지합니다. 반환값은 `{ start, end, svg, points, items }`이며 `points`에는 각 데이터 점의 SVG 요소가 들어 있습니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `el` | (필수) | 차트를 담을 빈 컨테이너 선택자 또는 요소 |
| `kind` | `"bar"` | `"bar"` 또는 `"line"` |
| `categories` / `values` | (필수) | 길이가 같은 비어 있지 않은 범주·유한한 음이 아닌 수치 배열 |
| `max` | 최댓값을 올림 | 양수인 축 상한. 데이터 최댓값 이상이어야 합니다 |
| `unit` | `""` | 값과 축에 붙이는 단위 |
| `color` | `"var(--eidos-cat-1)"` | 계열 색상 토큰 |
| `dur` | `1.2` | 막대 하나 또는 전체 선의 성장 시간(초) |
| `each` | `0.12` | 막대 시작 간격(초) |
| `at` | 이어서 | 시작 시각 |

## 변형
- **막대:** 기준선은 고정하고 높이와 y 좌표를 함께 바꿉니다. 완성 직전에 수치가 나타납니다
- **선:** 직선 구간의 실제 길이 비율에 맞춰 점과 값이 나타납니다. 급경사 구간도 선보다 점이 먼저 나오지 않습니다
- **비교:** 같은 단위의 두 차트를 비교할 때는 같은 `max`를 지정하세요

## reduced-motion
런타임이 다음 stop으로 즉시 이동합니다. 막대·선·점·값은 해당 지점의 완성 상태로 보이고 블러는 없습니다.
