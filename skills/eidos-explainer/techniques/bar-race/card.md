# 순위 경쟁 (Bar Race)

## 전달하는 의미
**시간이 흐르며 누가 누구를 앞지르는가.** 막대 길이는 시점 사이를 보간해 자라고 줄며, 값이 역전되는 근처에서 막대가 자리를 바꿉니다. 상위 K개 밖에서 올라오는 항목은 아래에서 떠오르고, 밀려나는 항목은 아래로 사라집니다. 오른쪽 아래의 큰 시점 표시가 지금 몇 월인지 알려 줍니다.

장면 관계: 장면 경계 전환이 아니라 장면 안에서 쓰는 기법(`kind: technique`)입니다. 스토리보드 concept 표에서 "순위가 시간에 따라 바뀐다" 행의 object(막대 무리)에 쓰고, `via`에는 쓰지 않습니다.

## 언제 쓰나
- 5~10개 항목의 순위가 시간에 따라 뒤바뀌는 것이 이야기의 핵심일 때 (엔드포인트별 호출 수, 서비스별 비용, 언어별 사용량)
- "언제 역전했나"를 짚어야 할 때. 그 시점에 스톱을 둡니다

## 피할 때
- 순위가 거의 바뀌지 않을 때. chart-grow가 더 정확합니다
- 시점이 2개뿐일 때. 전후 비교(split-screen, chart-morph)가 낫습니다
- 정확한 값 비교가 목적일 때. 움직이는 막대는 읽기 어렵습니다

## 사용법
```html
<div id="race"></div>   <!-- 빈 컨테이너. 높이를 주면 그 안에 맞춥니다 -->
```
```js
const race = stage.fx("bar-race", {
  el: "#race", top: 2, unit: "단위: 만 건", mono: true,
  items: [{ id: "search", label: "/search" }, { id: "feed", label: "/feed", color: "var(--eidos-accent)" }],
  rows: [
    { time: 1, label: "1월", values: { search: 48, feed: 12 } },
    { time: 3, label: "3월", values: { search: 51, feed: 52 } },
  ],
});                       // 첫 시점이 바로 그려짐
stage.tl.stop("1월");
race.to(3);               // 1월 → 3월을 보간하며 재생
stage.tl.stop("3월: /feed가 1위");
```
- **행 검사:** `time`이 없거나 유한수가 아닌 행은 버리고, 같은 `time`이 두 번 나오면 첫 행만 씁니다. 둘 다 오류 문장을 `__eidosErrors`와 콘솔에 남기므로 QA가 FAIL을 냅니다(그림은 남은 행으로 그대로 그립니다). 유효한 행이 2개 미만이면 예외를 던집니다. 행은 `time` 순으로 정렬합니다.
- **값:** 행에 없는 id는 0(아직 없음)입니다. 유한수가 아닌 값은 0으로 바꾸고, 모르는 id는 무시하며, 둘 다 오류를 남깁니다.
- **순위:** 값이 큰 순서, 값이 같으면 **id 오름차순**입니다. 입력 순서나 직전 순위와 무관하므로 몇 번을 다시 열어도 같은 순서입니다. 각 막대 그룹(`[data-eidos-item]`)에 지금 순위가 `data-eidos-rank`(0부터)로 붙습니다.
- **가로축:** 모든 행의 모든 값과 0을 포함하는 범위를 처음에 한 번 정해 고정합니다(보기 좋은 값으로 올림). 시점이 바뀌어도 축이 늘거나 줄지 않으므로 막대 길이를 시점끼리 바로 비교할 수 있습니다.
- **보간:** 두 시점 사이 값은 선형 보간입니다. 순위 위치는 한 구간을 8칸으로 나눠 칸마다 순위를 다시 매기고 그 사이를 이어 움직이므로, 추월이 실제로 값이 역전되는 근처에서 일어납니다. 시점에 정확히 도착하면 보간하지 않고 원래 값을 씁니다.
- **상위 K:** 순위가 K-1에서 K로 내려가는 동안 막대가 아래로 빠지며 투명해지고, 반대로 올라오면 떠오릅니다.
- 반환값: `{start, end, svg, rows, to(time, {at, dur, ease}), order(time)}`. `order(time)`은 그 시점의 id 순서, `rows`는 검사를 통과해 정렬된 행 복사본입니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `el` | (필수) | 차트를 넣을 빈 컨테이너 |
| `items` | (필수) | `{ id, label, color }` 2개 이상. id는 겹치지 않는 문자열 |
| `rows` | (필수) | `{ time, label, values }` 배열 |
| `top` | `min(항목 수, 5)` | 보여 줄 상위 K |
| `domain` | 자동 | `[min, max]`. 0과 모든 값을 포함해야 하며, 아니면 오류를 남기고 자동 범위를 씁니다 |
| `unit` | 없음 | 눈금 줄 왼쪽 끝에 그대로 쓰는 단위 문구 (예: `"단위: 만 건"`) |
| `format` | 반올림 정수 | 값 표시 함수 `(v) => string` |
| `mono` | `false` | 항목 이름을 고정폭 글꼴로 (경로, 패키지 이름) |
| `total` | `6` | 첫 시점부터 마지막 시점까지 재생하는 데 걸리는 초. `to()`의 기본 길이를 정합니다 |
| `at` | 이어서 | 첫 시점을 그리는 시각 |
| `to(time, {at, dur, ease})` | 거리 비례, `"inOut"` | 지금 시점에서 `time`까지 재생. 범위 밖 `time`은 오류 |

## 변형
- **긴 기간 한 번에:** 스톱 없이 `race.to(last)` 하나로 전체를 재생하고, 자동 재생(`P`)과 함께 씁니다
- **역전 순간 멈추기:** 역전이 일어나는 시점을 `rows`에 넣고 그 시점에서 `to()`를 끊어 스톱을 둡니다
- **범주가 5개를 넘을 때:** design-tokens.md의 "색을 더 만들 때"를 따라 `--eidos-cat-6` 같은 토큰을 라이트·다크 두 벌로 추가해 씁니다

## reduced-motion
좌표와 강조 상태는 각 트랙의 중간에서 다음 체크포인트로 즉시 바뀝니다. 이동·확대·순위 보간은 하지 않고, 런타임의 스톱 이동도 즉시 적용됩니다. `dur: 0`인 트랙은 정확한 시작 시각에서는 원래 상태를 유지하고 그 뒤에만 바뀝니다. 블러와 3D는 없습니다.
