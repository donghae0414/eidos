# 패럴랙스 (Parallax)

## 전달하는 의미
**멀리 있는 것은 느리게, 가까운 것은 빠르게 지나간다.** 카메라가 움직일 때 층마다 다른 속도로 움직여 깊이를 만듭니다. 설명에서는 깊이를 **추상화 수준**이나 **바뀌는 속도**로 읽게 씁니다. 느리게 움직이는 층은 바탕(오래 가는 것, 큰 맥락), 빠르게 지나가는 층은 표면(자주 바뀌는 것, 세부)입니다.

**장면 관계:** 한 장면 안의 층 사이 관계(바탕과 표면). 장면 경계가 아니므로 `via`가 아니라 `s.fx`로 부릅니다.

## 언제 쓰나
- 층마다 수명이나 변경 속도가 다를 때: 페이스 레이어링(UI → API → 스키마 → 인프라), 캐시 계층, 기술 스택
- 카메라가 옆으로 훑는 동안 바탕 맥락(리전, 조직, 시대)은 거의 그대로 두고 세부만 지나가게 할 때
- 제목, 범례, 층 이름을 카메라 이동 중에도 화면에 남기고 싶을 때 (`depth: -1`)

## 피할 때
- 층 사이 요소의 **위치가 서로 맞아야** 의미가 있을 때(위아래 칸이 같은 시각을 가리키는 표). 패럴랙스는 층을 서로 어긋나게 만듭니다.
- 카메라가 거의 움직이지 않는 장면. 패럴랙스는 카메라 이동이 있어야 보입니다.
- 크게 확대하는 카메라 이동. 배율 변화에는 층 차이가 없습니다(렌즈 줌). 다가가며 층이 갈라지는 효과는 zoom-in의 `mode: "dolly"`를 씁니다.

## 사용법
```html
<div class="track" data-parallax="0.6">...</div>    <!-- 가까운 층: 카메라보다 1.6배 빠르게 -->
<div class="track" data-parallax="0">...</div>      <!-- 기준 평면: 카메라와 같이 -->
<div class="track" data-parallax="-0.85">...</div>  <!-- 먼 층: 0.15배로 느리게 -->
<header data-parallax="-1">...</header>             <!-- 화면에 고정 -->
```
```js
stage.fx("parallax");    // [data-parallax] 요소를 모두 묶습니다
// 또는 stage.fx("parallax", { layers: [{ el: ".far", depth: -0.6 }] });
stage.camera.to((c) => ({ x: c.W * 1.4, y: c.H / 2, s: 1 }), { dur: 2.4, ease: "inOut" });
```
`depth`는 기준 평면보다 얼마나 가까운지입니다. `0`은 카메라와 똑같이, 음수는 멀어서 느리게(`-1`이면 화면에 고정), 양수는 가까워서 빠르게 움직입니다. 층의 화면 속도 = (1 + depth) × 카메라 속도. -1보다 작거나 유한수가 아닌 depth, 지원하지 않는 axis, 알 수 없는 옵션과 잘못된 옵션 타입은 `__eidosErrors`에 `parallax: ...` 오류를 남기고 예외를 던집니다.

카메라는 무엇으로 움직여도 됩니다(`camera.to`, pan, tracking, fly-to). 패럴랙스는 매 seek마다 카메라 위치를 읽어 층을 옮기므로 시간의 순수 함수입니다. 카메라가 기본 위치(전체 화면)에 있을 때 층은 HTML에 놓인 자리에 있습니다.

층의 `transform`은 이 기법이 씁니다. 같은 요소에 x, y, scale tween을 걸면 덮어쓰므로, 층에는 opacity만 tween하거나 층 안의 자식을 움직이세요. 층마다 이동 거리가 다르므로 층 내용은 그만큼 길게 깔아 둡니다. 필요한 길이 ≈ 보이는 폭 + (1 + depth) × 카메라 이동 거리.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `layers` | `[data-parallax]` 요소 | `[{ el, depth }]`. `el`은 선택자나 요소 |
| `depth` (`data-parallax`) | (필수) | -1 이상의 수. 화면 속도 = (1 + depth) × 카메라 속도 |
| `axis` | `"both"` (두 축 모두) | `"x"`면 가로 이동만, `"y"`면 세로 이동만 층에 반영 |

## 변형
- **고정 층:** `depth: -1`인 제목, 범례, 층 이름은 카메라가 옆으로 움직여도 화면에 남습니다(배율이 1일 때).
- **멀티플레인:** 층을 4개 이상 두면 깊이감이 커집니다. 다만 층마다 의미가 달라야 합니다. 장식용 층은 넣지 않습니다.

## reduced-motion
스톱 사이를 즉시 이동하고 200ms 페이드가 붙습니다. 각 스톱에서 층의 위치는 움직임을 켠 경우와 같고, 층이 서로 다른 속도로 미끄러지는 과정만 보이지 않습니다.

## 같이 쓰기 좋은 기법
pan(같은 배율로 옆으로 훑기, 패럴랙스가 가장 잘 보이는 카메라 이동), tracking(바탕은 느리게, 요청은 빠르게), zoom-in(`mode: "dolly"`로 다가가며 생기는 깊이)
