# 켄 번스 (Ken Burns)

## 전달하는 의미
**멈춰 있는 그림을 눈으로 따라 읽는다.** 정지된 그림(플레임 그래프, 큰 아키텍처 포스터, 대시보드 캡처) 위로 카메라가 천천히 다가가며 옆으로 흘러갑니다. 그림은 그대로이고 시선만 옮겨 가므로, "이 그림의 여기를 보세요"를 손가락 대신 카메라로 말합니다.

**장면 관계:** 같은 그림 안에서 시선을 옮김. 장면 경계가 아니므로 `via`가 아니라 `s.fx`로 부릅니다.

## 언제 쓰나
- 한 장으로 완성된 그림을 순서대로 읽어 줄 때: 플레임 그래프의 탑, 트레이스 워터폴의 긴 구간, 큰 다이어그램의 구역
- 그림 안 영역을 요소가 아니라 비율로 가리키고 싶을 때 (`[x, y, w, h]`, 0~1)
- 요소 단위 애니메이션이 없는 정적인 그림에 움직임을 줄 때

## 피할 때
- 그림 안의 요소가 직접 움직여야 의미가 생길 때 (흐름, 상태 변화). 그때는 tween이나 tracking을 씁니다.
- 대상 하나를 크게 보는 것이 목적일 때. zoom-in이 빠르고 분명합니다. 켄 번스는 느리고(기본 4.5초) 배율 변화가 작을 때 어울립니다.
- 스톱에 멈춘 동안에도 계속 떠다니게 하고 싶을 때. EIDOS는 정지 중 움직임을 금지합니다. 켄 번스도 스톱과 스톱 사이에서만 움직입니다.

## 사용법
```js
const kb = stage.fx("ken-burns", {
  in: ".graph",              // 비율 사각형의 기준이 되는 그림 요소
  to: [0, 0, 0.6, 1],        // [x, y, w, h], in 요소 크기에 대한 비율
  dur: 4.5,
});
stage.tl.stop("가장 넓은 탑: loadConfig");
kb.drift([0.44, 0.04, 0.48, 0.96]);   // 옆으로 흐르며 조금 더 다가가기
stage.tl.stop("두 번째 탑: compileTemplate");
kb.drift("world", { dur: 3 });        // 전체로 돌아오기
```
비율 사각형은 여백 없이(`pad: 0`) 화면에 맞춰 잘라 보여 줍니다. 사각형의 가로세로 비가 화면과 다르면 한쪽 방향으로 더 보입니다. 잘못된 사각형(길이가 4가 아니거나 유한수가 아니거나 w, h가 0 이하)은 `__eidosErrors`에 `ken-burns: ...` 오류를 남기고 예외를 던집니다. 알 수 없는 옵션과 잘못된 옵션 타입도 같은 방식으로 거부합니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `to` | (필수) | 도착 구도. `[x, y, w, h]` 비율, 선택자, 요소, `{x, y, w, h}`(world px), `"world"` |
| `from` | 없음 | 시작 구도. 주면 `at`에서 그 구도로 바로 자른 뒤 흐릅니다. 없으면 지금 카메라 위치에서 출발합니다 |
| `in` | world의 첫 자식 요소 | 비율 사각형의 기준 요소 |
| `dur` | `4.5` | 이동 시간(초). 3초보다 짧으면 zoom-in과 구분되지 않습니다 |
| `ease` | 부드러운 sine 계열 in-out | 시작과 끝만 살짝 감속하고 중간은 거의 같은 속도 |
| `pad` | 비율 사각형 `0`, 그 밖 화면 짧은 변의 8% | 구도 여백(px) |
| `at` | 타임라인 끝 | 시작 시점 |
| `drift(to, { from, dur, ease, pad, at })` | 위와 같음 | 같은 `in` 기준으로 다음 구도까지 흐르기 |

## 변형
- **푸시 + 팬:** 다음 사각형을 조금 작게(배율 차이 1.1~1.3배) 잡으면 옆으로 흐르면서 다가가는 고전적인 켄 번스가 됩니다. 템플릿의 두 번째 이동이 이 방식입니다.
- **팬 앤 스캔:** 같은 크기의 사각형을 이어서 지나가면 배율 변화 없이 훑습니다. 단계가 한 줄로 놓인 흐름이면 pan이 더 정확합니다.

## reduced-motion
스톱 사이를 즉시 이동하고 200ms 페이드가 붙습니다. 각 스톱의 구도는 움직임을 켠 경우와 같습니다.

## 같이 쓰기 좋은 기법
highlight-sweep(도착한 구역의 핵심 칸 강조), freeze-frame(도착한 구도에 주석 달기), zoom-in(한 칸을 더 깊이)
