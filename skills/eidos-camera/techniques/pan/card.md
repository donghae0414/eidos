# 패닝 (Pan)

## 전달하는 의미
**같은 크기로, 순서대로 읽는다.** 배율은 그대로 두고 카메라만 한 방향으로 움직입니다. 한 화면에 다 담으면 글씨가 작아지는 긴 흐름(파이프라인, 타임라인, 단계)을 읽을 수 있는 크기로 한 칸씩 훑습니다. 세로로 움직이면 틸트입니다.

## 언제 쓰나
- 단계가 5개 이상인 가로 흐름: CI/CD, 데이터 파이프라인, 요청 처리 단계, 연혁
- 세로로 쌓인 계층: 네트워크 계층(OSI), 콜 스택, 조직도 한 갈래 (`axis: "y"`, 틸트)
- 전체를 먼저 보여준 뒤(설정숏) 한 칸씩 읽어 갈 때

## 피할 때
- 단계가 3개 이하라 한 화면에 읽히는 크기로 들어갈 때. 움직일 이유가 없습니다.
- 단계 사이 거리가 의미를 가질 때(시간 축 비율). 패닝은 같은 간격으로 걷는 느낌을 줘서 거리를 숨깁니다.

## 사용법
```js
stage.camera.to(".strip", { at: 0, dur: 0, pad: 24 });  // 시작: 전체를 한 화면에
stage.fx("pan", {
  items: ".st",            // 차례로 멈출 요소들
  axis: "x",               // "x" 패닝, "y" 틸트
  active: true,            // 현재 칸만 선명하게
  captions: ["1. Push", "2. 빌드", "3. 테스트"],   // 칸마다 stop
});
stage.camera.to(".strip", { dur: 1.4, pad: 24 });     // 끝: 다시 전체
```
카메라 중심은 `line`(기본: 첫 요소의 부모) 의 중앙선 위에 고정되고, 이동 축만 바뀝니다. 그래서 칸 사이를 움직이는 동안 배율이 정확히 같습니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `items` | (필수) | 멈출 요소들 |
| `axis` | `"x"` | `"x"` 가로 패닝, `"y"` 세로 틸트 |
| `zoom` | `1` | 고정 배율 |
| `line` | 첫 요소의 부모 | 카메라가 따라갈 기준선 요소 |
| `dur` | `1.2` | 칸 사이 이동 시간(초) |
| `enterDur` | `dur` | 첫 칸으로 들어가는 시간 |
| `active` / `dimTo` | `false` / `0.45` | 현재 칸만 선명하게 |
| `captions` | `[]` | 칸마다 stop 캡션 |

## 변형
- **틸트:** `axis: "y"`. 템플릿은 세로 화면(모바일)에서 칸을 세로로 쌓고 자동으로 틸트로 바뀝니다. 축은 빌드 시점의 화면 비율로 정하므로, 가로/세로를 바꾸면 새로고침해야 합니다.
- **무한 캔버스 패닝:** 칸 사이에 연결선이나 배경 띠를 두면 긴 지도를 걷는 느낌이 납니다.

## reduced-motion
칸 사이를 즉시 이동하고 200ms 페이드가 붙습니다.

## 같이 쓰기 좋은 기법
establishing-shot(먼저 전체), zoom-in(한 칸을 더 깊이), stagger-reveal(칸 안의 항목 순서대로)
