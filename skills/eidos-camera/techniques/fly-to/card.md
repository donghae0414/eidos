# 플라이 투 (Fly-to)

## 전달하는 의미
**멀리 떨어진 두 곳이 이어져 있고, 그 사이는 멀다.** 카메라가 한 지점에서 위로 빠져(줌아웃) 두 곳이 함께 보이는 높이까지 오른 뒤, 옮겨 가서 다른 지점에 내려앉습니다(줌인). 지도 앱이 도시 사이를 날아가는 방식입니다. 가운데 높이에서 출발지와 목적지가 한 화면에 잡히므로 거리와 방향을 잃지 않습니다.

**장면 관계:** 같은 그림 안의 먼 두 부분을 잇는 이동. 장면 경계에서 같은 비행을 쓰려면 `via: "camera"`에 `with: { arc: 0.6 }`을 넘깁니다.

## 언제 쓰나
- 확대한 상태에서 멀리 있는 다른 대상으로 옮겨 갈 때: 엣지 → 원본 서버, 서비스 A → 다른 리전의 서비스 B, 지도 위 두 도시
- 거리 자체가 설명의 일부일 때 (지연 시간, 홉 수, 리전 간 비용)
- 그냥 `camera.to`로 옮기면 화면이 빠르게 미끄러져 어디에서 어디로 갔는지 놓칠 때

## 피할 때
- 두 대상이 가까워 확대한 채로도 함께 보일 때. 오를 이유가 없습니다(`arc`를 줘도 거의 오르지 않습니다).
- 전체 화면에서 한 곳으로 들어갈 때. 그건 zoom-in입니다.
- 모든 이동에 쓰기. 오르내림이 반복되면 어지럽습니다. 먼 이동에만 씁니다.

## 사용법
```js
stage.camera.to("#icn", { zoom: 2.2 });          // 먼저 출발지를 확대한 상태
stage.tl.stop("서울 엣지: 캐시 MISS");
stage.fx("fly-to", {
  target: "#iad",          // 내려앉을 곳
  arc: 0.7,                // 0이면 평범한 camera.to, 1이면 가운데에서 두 지점이 한 화면에 들어오는 높이
  zoom: 2.2,
  route: ".route-go",      // (선택) 날아가는 동안 그릴 SVG path
  from: "#icn",            // route의 출발 요소
  reveal: "#iad .detail",  // 도착하며 나타날 요소
});
stage.tl.stop("원본까지 왕복 180ms");
```
카메라 자체에 같은 옵션이 있습니다: `stage.camera.to(target, { arc: 0.5 })`. 이 기법은 그 위에 기본값(`arc 0.6`, `dur 2.4`)과 경로 그리기, 도착 reveal을 더한 것입니다. `arc: 0`이면 `camera.to`와 같은 경로입니다.

`arc`는 0부터 1까지의 유한수입니다. `s.fx("fly-to", ...)`는 범위 밖 값이나 숫자가 아닌 값, 알 수 없는 옵션과 잘못된 옵션 타입을 `__eidosErrors`에 `fly-to: ...` 오류로 기록한 뒤 예외를 던집니다. 직접 쓰는 `camera.to`의 arc 오류 처리(경계값 또는 0으로 보정)는 그대로입니다.

`route` path가 든 SVG는 어디에 두어도 됩니다. 경로 좌표는 그 SVG 상자 기준으로 계산하므로, 지도 요소의 첫 자식으로 `position: absolute; inset: 0`을 주면 지도 배경 위, 카드 아래에 그려집니다. 경로는 `from` 중심에서 `target` 중심까지 휘는 곡선이라 양 끝이 카드에 가려 자연스럽습니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `target` | (필수) | 도착할 대상 (선택자, 요소, `{x, y, w, h}`) |
| `arc` | `0.6` | 오르는 높이. 0 = 직선 이동, 1 = 가운데 시야가 출발 구도와 도착 구도를 합친 폭만큼 넓어짐(두 구도의 배율이 같으면 둘 다 온전히 담김) |
| `dur` | `2.4` | 이동 시간(초). 오르내림이 있으므로 camera.to보다 길게 잡습니다 |
| `zoom` / `pad` | 자동 | 도착 배율과 여백 |
| `ease` | `"camera"` | 이동 곡선 |
| `route` | 없음 | 이동 중 그릴 SVG `path`. `from`이 없으면 path에 미리 적어 둔 `d`를 그립니다 |
| `from` | 없음 | `route` 곡선의 출발 요소 |
| `bend` | `0.2` | 경로가 휘는 정도. 양수면 진행 방향의 왼쪽으로 휩니다 |
| `reveal` | 없음 | 도착 직전에 나타날 요소 |
| `at` | 타임라인 끝 | 시작 시점 |

## 변형
- **장면 경계 비행:** `s.scene("origin", { el: "#origin", via: "camera", with: { arc: 0.6, dur: 2.4 } })`. 갈래(`s.spoke`)와 복귀(`s.back`)의 `with`에도 같은 옵션을 넘길 수 있습니다.
- **왕복:** 돌아올 때는 다른 path와 다른 색으로 `fly-to`를 한 번 더 부릅니다. `bend`가 같으면 돌아오는 경로는 반대쪽으로 휘어 두 경로가 겹치지 않습니다.

## reduced-motion
오르내림 없이 출발과 도착 구도로 즉시 이동하고 200ms 페이드가 붙습니다. 경로는 도착 스톱에서 다 그려진 상태로 보입니다.
