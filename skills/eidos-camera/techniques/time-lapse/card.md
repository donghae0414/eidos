# 타임랩스 (Time-lapse)

## 전달하는 의미
**긴 시간이 압축되어 흐르고, 그동안 상태는 이렇게 바뀌었다.** 시각이 붙은 상태 기록(스냅숏)을 시계와 함께 빠르게 넘깁니다. 시계는 끊김 없이 흐르고, 화면은 그 시각까지 기록된 마지막 스냅숏으로 한 칸씩 바뀝니다. 하루, 한 분기, 한 해 동안의 변화를 몇 초 안에 보여 줍니다.

**장면 관계:** 같은 장면의 긴 시간 경과. 배치는 그대로이고 상태만 바뀝니다. `via`가 아니라 `s.fx`로 부릅니다.

## 언제 쓰나
- 시간에 따라 쌓이거나 출렁이는 상태: 오토스케일링 하루, 커밋 히스토리, 디스크 사용량, 큐 길이, 에러율
- 데이터가 이미 시각별 기록으로 있을 때 (`frames: [{ at, ... }]`)
- 원인과 결과 사이에 시간 차가 있을 때 (트래픽이 줄고 한 시간 뒤에 파드가 줄어듦)

## 피할 때
- 상태가 몇 개뿐일 때. 스톱마다 하나씩 보여 주세요.
- 중간 값을 부드럽게 이어야 의미가 있을 때 (위치 이동). 타임랩스는 기록 사이를 보간하지 않고 건너뜁니다. 보간이 필요하면 tween을 씁니다.
- 기록 간격이 들쭉날쭉한데 그 간격을 숨기면 안 될 때. 시계가 일정하게 흐르므로 빈 구간은 화면이 멈춘 것처럼 보입니다.

## 사용법
```js
const lapse = stage.fx("time-lapse", {
  frames: [{ at: 0, rps: 140, pods: 2 }, { at: 1, rps: 100, pods: 2 }, /* ... */ { at: 24, rps: 180, pods: 4 }],
  render: (f, u) => { /* f만 보고 화면 전체 상태를 정함 */ },
  counter: "#clock",                                       // 시계 요소 (선택)
  format: (u) => `${String(Math.floor(u)).padStart(2, "0")}:00`,
  from: 0, to: 9, dur: 3.2,                                // 기록 시각 0 → 9를 3.2초 동안
});
stage.tl.stop("출근 시간: 파드가 2개에서 5개로");
lapse.to(20, { dur: 3.6 });                                // 이어서 20시까지
stage.tl.stop("저녁 8시 피크");
```
`render(frame, u)`는 **그 프레임만 보고** 화면 전체를 다시 칠해야 합니다. 이전 프레임에서 바뀐 부분만 고치거나 요소를 추가하면 뒤로 가기와 URL 새로고침에서 화면이 달라집니다. 필요한 요소는 `start()` 전에 모두 만들어 두고 class, 속성, 텍스트, 스타일 값만 바꿉니다. 두 번째 인자 `u`는 지금 기록 시각(연속값)이라 시계 바늘이나 "지금" 표시선처럼 끊김 없이 움직일 요소에 씁니다.

프레임 선택 규칙: 기록 시각 `u`에서 `at <= u`인 마지막 프레임. `u`가 첫 프레임보다 이르면 첫 프레임입니다. 프레임이 비었거나 `at`이 오름차순 유한수가 아니거나 `render`가 함수가 아니면 `__eidosErrors`에 오류를 남기고 아무것도 기록하지 않습니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `frames` | (필수) | `at`(기록 시각, 오름차순)이 있는 객체 배열 |
| `render` | (필수) | `(frame, u) => void`. 프레임으로 화면 상태를 정하는 순수 함수 |
| `counter` | 없음 | 시계를 쓸 요소. `format(u)`의 결과가 텍스트로 들어갑니다 |
| `format` | 반올림한 숫자 | 시계 문자열 |
| `from` / `to` | 첫 프레임 / 마지막 프레임 시각 | 이번 구간이 지나갈 기록 시각 |
| `dur` | `4` | 구간 재생 시간(초) |
| `ease` | `"linear"` | 시계가 흐르는 곡선. 타임랩스는 일정한 속도가 자연스럽습니다 |
| `at` | 타임라인 끝 | 시작 시점 |
| `to(u, { dur, ease, at })` | | 앞 구간이 끝난 기록 시각에서 이어 `u`까지 흐르기 |

## 변형
- **누적 표시:** render에서 `at <= frame.at`인 기록을 모두 그리면(스파크라인, 커밋 점) 흔적이 쌓이는 타임랩스가 됩니다. 템플릿의 하루 요청량 그래프가 이 방식입니다.
- **되감기:** `lapse.to(0)`처럼 더 이른 시각을 주면 거꾸로 흐릅니다.

## reduced-motion
스톱 사이를 즉시 이동하므로 시계와 상태가 바로 그 스톱의 시각으로 바뀝니다. 중간 프레임은 보이지 않습니다.
