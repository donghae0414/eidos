동기 vs 비동기

주문 직후 결제를 어떻게 부를까

동기 처리

결제가 끝날 때까지 기다린다

const res = await payment.charge(order)
return res.ok ? 201 : 402
주문 요청PG 응답 대기 3초201 응답

사용자는 3초 동안 로딩 화면을 봅니다. PG가 느려지면 주문 API도 같이 느려집니다.

비동기 처리

큐에 넣고 바로 답한다

await queue.publish("order.created", order)
return 202  // 결제는 워커가 처리
주문 요청큐 적재 15ms202 응답

사용자는 바로 다음 화면으로 갑니다. 대신 결제 실패를 나중에 알려줘야 합니다.
