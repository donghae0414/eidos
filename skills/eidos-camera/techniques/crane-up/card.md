# 크레인업 (Crane Up)

## 전달하는 의미
**이 작은 것은 저 높은 구조의 맨 아래에 있다.** 카메라가 바닥 높이에서 세부 하나를 보다가 위로 솟으며 물러납니다. 처음에는 화면이 살짝 뒤로 누워 있어(rotateX) 바닥에 선 시점이고, 올라갈수록 평평해지며 위에서 내려다보는 시점이 됩니다. 주변 맥락은 아래층부터 차례로 드러나서, 카메라가 층을 지나 올라간다는 느낌을 줍니다.

**장면 관계:** 세부에서 맥락으로 물러남. 장면 경계가 아니라 한 장면 안의 카메라 이동이므로 `via`가 아니라 `s.fx`로 부릅니다.

## 언제 쓰나
- 세부가 **세로로 쌓인 구조의 아래쪽**에 있을 때: 호출 스택(앱 → 런타임 → libc → 커널), 네트워크 계층, 인프라 계층, 조직도의 말단
- "이 낮은 수준의 일은 사실 위에서 시킨 것"이라는 인과를 보여줄 때 (시스템 콜이 어느 코드에서 왔는지)
- 첫 장면에서 사용자가 아는 바닥의 한 점에서 시작해 전체 높이를 드러낼 때

## 피할 때
- 세부와 맥락이 위아래가 아니라 옆이나 안팎 관계일 때. 그때는 establishing-shot의 `pullBack()`이 정직합니다. 크레인업은 수직 이동과 기울기가 의미를 가집니다.
- 기울어진 화면에서 읽어야 할 글이 많을 때. 시작 구도는 세부 하나만 읽히면 충분합니다.
- 한 작품에서 여러 번. 수직 상승은 한 번일 때 극적입니다.

## 사용법
```js
const crane = stage.fx("crane-up", {
  from: "#syscall",     // 바닥 높이에서 처음 볼 세부 요소
  context: ".ctx",      // 클로즈업 동안 숨겼다가, 올라가며 아래층부터 드러낼 요소들
  tilt: 12,             // 시작 기울기(도). 세부를 축으로 위쪽이 뒤로 눕습니다
});
stage.tl.stop("커널 안의 read() 하나만 보면 누가 불렀는지 모릅니다");
crane.rise({ to: "world", dur: 2.2 });   // 솟아오르며 물러나기, 기울기는 0으로
stage.tl.stop("위로 올라가면 앱 코드에서 내려온 호출입니다");
```
`from`은 맥락 아래쪽에 있어야 카메라 경로가 수직이 됩니다(크레인업의 translateY). 기울기는 `rig` 요소에 걸리며, 축은 `from` 요소의 중심이라 클로즈업 동안 세부가 화면 밖으로 밀리지 않습니다.

`tilt`는 유한한 숫자여야 합니다(reduced-motion에서도 검사). 알 수 없는 옵션과 잘못된 옵션 타입은 `__eidosErrors`에 `crane-up: ...` 오류를 남기고 예외를 던집니다. 이어지는 `rise()`는 앞 상승의 끝 상태(맥락 opacity 1, 기울기 0)에서 출발하므로 중간 스톱을 그대로 보존합니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `from` | (필수) | 처음 클로즈업할 세부 요소 |
| `context` | 없음 | 클로즈업 동안 숨기고, 올라가는 동안 아래쪽 요소부터 차례로 나타낼 요소 |
| `tilt` | `12` | 시작 rotateX(도). 10~16 사이가 자연스럽습니다. 0이면 기울기 없음 |
| `rig` | world의 첫 자식 요소 | 기울어질 요소. 장면 전체를 감싼 요소를 고릅니다 |
| `openZoom` / `pad` | 자동 / 화면 짧은 변의 8% | 클로즈업 배율과 여백 |
| `introDur` | `0.6` | 첫 세부가 나타나는 시간 |
| `at` | 타임라인 끝 | 시작 시점 |
| `rise({ to, dur, ease, pad, zoom, at })` | `to "world"`, `dur 2.2`, `ease "camera"` | 솟아오르기. 기울기는 `dur`의 85% 동안 0으로 펴집니다 |

## 변형
- **중간 높이에서 멈추기:** `rise({ to: "#runtime-layers" })`처럼 world 대신 중간 영역까지만 올라갑니다. 다시 `rise({ to: "world" })`를 부르면 두 단계로 솟습니다(기울기는 첫 번째 rise에서 이미 0).
- **기울기 없는 크레인:** `tilt: 0`. 수직 경로와 아래층부터 드러나는 순서만 남습니다.

## reduced-motion
기울기(rotateX)를 아예 걸지 않습니다. 카메라는 클로즈업과 전체 구도로 즉시 이동하고 200ms 페이드가 붙습니다. 맥락 요소는 rise가 끝난 정지 지점에서 모두 보입니다.

## 같이 쓰기 좋은 기법
path-drawing(올라온 뒤 호출 경로를 위에서 아래로 그리기), zoom-in(전체를 본 뒤 다른 층으로 다시 들어가기), establishing-shot(수직 관계가 아닌 맥락 보여주기)
