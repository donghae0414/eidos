# 자간 수렴 (Tracking Reveal)

**장면 관계:** 한 장면 안에서 제목이나 섹션 이름 하나를 자리에 앉힐 때 씁니다. 장면 경계의 `via` 값이 아니므로 `s.fx`로 부릅니다.

## 전달하는 의미
**흩어져 있던 것이 하나로 정돈된다.** 넓게 벌어져 있던 글자가 서로 당겨지며 제목이 한 덩어리로 자리를 잡으면, "지금부터 이 이름 아래에서 이야기한다"는 차분한 선언이 됩니다. 소리 내어 읽는 리듬(kinetic-type)도, 결론을 내리꽂는 단언(mask-reveal)도 아닌, 장(chapter)이나 개념 이름이 조용히 제자리를 찾는 느낌입니다.

## 언제 쓰나
- 장이나 섹션의 제목 카드. 다음 장면들이 모두 이 이름 아래 놓일 때
- 제품, 프로젝트, 개념의 이름 한 단어를 처음 소개할 때 ("컨텍스트 윈도우", "RAG")
- 긴 설명 뒤에 짧은 부제 한 줄을 정착시키며 마무리할 때

## 피할 때
- 한 장면에 한 번 넘게. 같은 등장이 반복되면 정돈의 느낌이 장식이 됩니다. 장면마다 제목 하나에만 씁니다
- 본문 문단이나 긴 문장. 글자마다 움직이면 읽기를 방해합니다. 제목 한 줄, 10자 안팎에만 씁니다
- 줄 한쪽의 남는 여백보다 `spread × (글자 수 - 1) / 2`가 큰 제목. 글자는 정렬과 상관없이 줄 가운데를 기준으로 양쪽으로 벌어지므로 왼쪽 정렬 제목도 앞 절반이 왼쪽 여백으로 나갑니다. 390px 폭에서 글자가 화면 밖으로 나가면 `spread`를 줄이거나 제목을 두 줄로 나누세요
- 값이 계산되어 나오는 느낌(text-scramble), 단어별 강세(kinetic-type)가 필요한 자리

## 사용법
```html
<div class="eidos-label" id="label">LLM 기초 · 3장</div>
<h1 class="hero" id="title">컨텍스트 윈도우</h1>
```
```js
s.tl.tween("#label", { opacity: [0, 1] }, { dur: 0.4 });
s.fx("tracking-reveal", { targets: "#title", at: "<+=0.1" });   // 벌어진 글자가 모이며 제목이 정착
s.tl.stop("3장: 컨텍스트 윈도우");
```
**글자 나누기.** 기법이 대상 요소의 글자를 공백 기준으로 단어(`span.eidos-word`, inline-block, 줄바꿈 금지)로 묶고, 그 안을 한 글자씩 `span.eidos-glyph`(inline-block)로 나눕니다. 한국어는 어절이 한 단어이고, 대상에 `word-break: keep-all`을 걸어 어절 중간에서 줄이 바뀌지 않습니다. 대상 안의 자식 요소(`<b>`, `<code>`)는 쪼개지 않고 글자 하나처럼 움직입니다.

**벌어지는 기준.** 시작 위치는 `s.start()`의 레이아웃 단계에서 실제 줄(행)마다 다시 계산합니다. 한 줄의 글자 `i`는 `(i - center) × spread` px에서 0으로 돌아오며, `center = (글자 수 - 1) / 2`는 그 줄의 가운데입니다. 대상의 `text-align`과 상관없이 언제나 줄 가운데를 기준으로 양쪽으로 벌어집니다(왼쪽 정렬이면 앞 절반은 왼쪽 여백으로 나갑니다). 모바일에서 제목이 두 줄로 접히면 각 줄이 따로 자기 가운데로 모입니다. 화면 크기가 바뀌면 런타임이 레이아웃을 다시 돌려 줄 나눔을 다시 잡습니다.

`letter-spacing`은 건드리지 않습니다. 글자 위치는 `transform`으로만 움직이므로 줄 폭이 흔들리거나 다시 접히는 일이 없습니다. 불투명도는 앞 60% 동안 0에서 1로 올라오고, 이동은 `ease`로 끝까지 모입니다. 글자 span의 `transform`과 `opacity`는 이 기법이 씁니다. 대상 요소 자체(`#title`)에는 다른 트윈을 걸어도 됩니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `targets` | (필수) | 제목 요소들. 여러 개면 같은 시각에 함께 모입니다 |
| `spread` | `14` | 시작할 때 이웃 글자 사이에 더 벌어진 간격(px). 글자 크기의 0.2배 안팎이 적당합니다(70px 제목이면 14, 36px 제목이면 7). 음수면 겹친 상태에서 벌어지며 자리를 잡습니다 |
| `dur` | `0.9` | 모이는 시간(초). 0.6~1.2 사이에서 천천히 |
| `ease` | `"camera"` | 이동 이징. `camera`는 끝이 부드럽게 멈추고, `out`은 더 빨리 모입니다. 불투명도 곡선은 바뀌지 않습니다 |
| `at` | 이어서 | 시작 시각 |

반환값: `{ start, end, items: [{ el, glyphs, start, end }] }`. `el`은 대상 요소, `glyphs`는 글자 span 배열입니다.

## 변형
- **긴 한국어 제목:** `spread: 8`로 줄이면 벌어진 상태에서도 글자가 서로 무관한 조각처럼 보이지 않습니다
- **영문 대문자 제목:** `spread: 18, dur: 1.1`이면 "COLLECTION"처럼 브랜드 타이틀의 느린 정착이 됩니다
- **두 줄 제목:** `targets: ".title .line"`처럼 줄 요소 두 개를 함께 주면 두 줄이 같은 시각에 각자 모입니다
- **부제 정착:** 작은 글자의 부제에 `spread: 6, dur: 0.7`을 주면 제목 아래 한 줄이 조용히 앉습니다

## reduced-motion
글자가 이동 없이 제자리에서 불투명도만 0 → 1로 올라옵니다. 런타임이 stop 사이를 즉시 건너뛰므로 보통은 완성된 제목만 보입니다. 블러와 3D는 쓰지 않습니다.

## 같이 쓰기 좋은 기법
mask-reveal(제목 아래 결론 한 줄을 선언할 때는 그쪽), highlight-sweep(정착한 제목의 핵심어를 짚을 때), kinetic-type(단어별 강세가 필요한 문장은 그쪽, 제목 정착은 이쪽), stagger-reveal(제목 아래 항목들을 차례로 세울 때)
