# 딥 투 컬러 (Dip to Color)

## 전달하는 의미
**여기서 한 장이 끝나고 다음 장이 시작된다.** 화면이 한 색으로 완전히 덮였다가 새 장면으로 열립니다. 덮인 순간 앞 장면의 흔적이 모두 지워지므로, 이어지는 단계가 아니라 새 장(chapter)이라는 큰 구분을 전합니다. 덮인 동안 장 제목을 보여줄 수 있습니다.

**장면 관계:** 장(chapter)이 바뀜. 스토리보드가 `layered-chapters` 구조이거나 장면 묶음 사이 경계일 때 `via: "dip-to-color"`를 씁니다.

## 언제 쓰나
- 세대, 버전, 단계처럼 큰 덩어리가 바뀔 때 (HTTP/1.1 → HTTP/2 → HTTP/3)
- 도입부에서 본론으로, 본론에서 정리로 넘어갈 때
- 허브 앤 스포크에서 마지막 허브 복귀 뒤 아웃트로로 나갈 때

## 피할 때
- 같은 장 안의 작은 단계 사이. 매번 덮으면 흐름이 끊깁니다. cross-dissolve나 jump-cut을 쓰세요.
- 장 제목이 장면 헤더와 똑같은 말만 반복할 때. 그때는 `title` 없이 짧게(`dur: 0.8`) 씁니다.
- 강조색을 덮는 색으로 계속 쓸 때. 강조색은 "여기를 보라"는 뜻이라 장 구분에는 `fg`나 범주색이 낫습니다.

## 사용법
```js
s.scene("h1", { el: "#a" });
// ...
s.scene("h2", { el: "#b", via: "dip-to-color", with: { title: "2장 · HTTP/2" }, reason: "장이 바뀜" });
s.scene("h3", { el: "#c", via: "dip-to-color", with: { color: "cat-4", title: "3장 · HTTP/3" } });
```
덮는 레이어는 world 바로 뒤에 하나 만들어지므로 카메라 위치와 상관없이 화면 전체를 덮습니다. 장면 교체는 완전히 덮인 구간의 한가운데에서 일어납니다. 제목 글자색은 덮는 색에 맞춰 자동으로 고릅니다(`fg` 위에는 `bg`, `bg`·`surface` 위에는 `fg`, 그 밖에는 `accent-fg`).

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `from` / `to` | 런타임이 채움 | 나가는 장면 / 들어오는 장면 |
| `color` | `"fg"` | 덮는 색. `--eidos-*` 토큰 이름(`fg`, `bg`, `accent`, `cat-2` …). 없는 토큰이면 오류 |
| `title` | 없음 | 덮인 동안 가운데에 보여줄 장 제목 |
| `dur` | 제목 있음 `2`, 없음 `1.2` | 전체 시간(초): 덮기 → 머물기 → 열기 |
| `hold` | 제목 있음 `0.4`, 없음 `0.15` | 완전히 덮인 채 머무는 비율(0~1 미만) |
| `ease` | `"inOut"` | 덮기와 열기의 이징 |
| `at` | 타임라인 끝 | 시작 시점 |

## 변형
- **딥 투 블랙(테마 대응):** 기본값 `color: "fg"`. 라이트 테마에서는 어두운 색, 다크 테마에서는 밝은 색으로 덮습니다.
- **챕터 인터스티셜:** `title`을 주고 `hold`를 늘립니다. 장 번호와 한 줄 요약을 함께 씁니다.
- **색 딥:** `color: "cat-4"`처럼 장마다 범주색을 정해 두면 색만으로 몇 장인지 기억됩니다.

## reduced-motion
덮기와 열기는 원래 페이드라 그대로 두고, 제목의 위로 떠오르는 움직임만 끕니다. 스톱 사이 이동은 런타임이 즉시 처리하므로 실제로는 장면이 바로 바뀌고 화면 전체가 200ms 동안 옅게 페이드됩니다.

## 같이 쓰기 좋은 기법
establishing-shot(새 장의 전체 그림부터 보여주기), kinetic-type(장 제목을 더 강하게), stagger-reveal(새 장의 요소 순서대로 띄우기)
