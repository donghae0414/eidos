# 점프컷 (Jump Cut)

## 전달하는 의미
**같은 그림, 시간만 건너뛰었다.** 구도와 배치는 그대로 두고 상태만 순간 바뀝니다. 80ms짜리 짧은 깜빡임이 "여기서 시간이 잘렸다"는 표시가 되어, 중간 과정은 중요하지 않고 앞뒤 상태의 차이가 요점이라는 뜻을 전합니다.

**장면 관계:** 같은 그림의 나중 상태. 스토리보드 경계 표에서 두 장면이 같은 다이어그램의 단계(1단계 → 3단계)일 때 `via: "jump-cut"`을 씁니다.

## 언제 쓰나
- 같은 다이어그램의 단계별 상태 (git 브랜치가 갈라지고 합쳐짐, 큐가 차고 비워짐)
- 중간 과정을 애니메이션으로 보여주면 오히려 길고 산만할 때
- 같은 배치의 표나 그래프에서 숫자만 바뀐 버전을 차례로 보여줄 때

## 피할 때
- 두 장면의 배치가 다를 때. 레이아웃이 튀어 보이기만 하고 "같은 그림"이라는 뜻이 사라집니다. wipe나 cross-dissolve를 쓰세요.
- 변화 과정 자체가 설명일 때. 그때는 장면 안 tween이나 shape-morph로 움직임을 보여주세요.
- 깜빡임을 연달아 여러 번. 리듬이 필요하면 `flash: false`로 번갈아 씁니다.

## 사용법
```js
s.scene("main", { el: "#a" });
// ...
s.scene("branch", { el: "#b", via: "jump-cut", reason: "같은 그림의 나중 상태" });
s.scene("merged", { el: "#c", via: "jump-cut", with: { flash: false } });
```
세 장면은 같은 위치에 같은 구조로 만들어 두고 내용만 다르게 합니다. 바뀐 요소만 눈에 띄게 하려면 바뀌지 않는 부분의 마크업과 스타일을 그대로 복사하세요. 장면 교체는 0초이고, `dur`은 그 뒤 깜빡임 길이입니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `from` / `to` | 런타임이 채움 | 나가는 상태 / 들어오는 상태 |
| `flash` | `true` | 교체 순간 화면 전체를 `--eidos-fg` 색으로 아주 잠깐 어둡게. `true`/`false` 밖의 값은 오류 |
| `dur` | `0.08` | 깜빡임 길이(초). `flash: false`면 0 |
| `strength` | `0.22` | 깜빡임 최대 불투명도 |
| `at` | 타임라인 끝 | 교체 시점 |

## 변형
- **플래시 점프컷:** 기본값. 단계가 바뀌었음을 확실히 알립니다.
- **조용한 점프컷:** `flash: false`. 연속된 단계 사이, 또는 변화가 이미 눈에 잘 띌 때.
- **연속 점프컷:** 같은 그림의 상태 3~4개를 짧은 스톱으로 이어 붙이면 타임랩스처럼 읽힙니다(같은 via 3번까지 규칙 안에서).

## reduced-motion
깜빡임을 만들지 않고 0초 컷만 남깁니다. 스톱 이동 시 런타임이 화면 전체를 200ms 동안 옅게 페이드합니다.

## 같이 쓰기 좋은 기법
highlight-sweep(점프 뒤 바뀐 부분 짚기), freeze-frame(마지막 상태에 주석 달기), shape-morph(변화 과정 자체를 보여줘야 할 때의 대안)
