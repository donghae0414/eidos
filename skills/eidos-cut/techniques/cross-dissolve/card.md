# 크로스디졸브 (Cross Dissolve)

## 전달하는 의미
**장면이 바뀌지만 이어진다.** 앞 장면이 옅어지는 동안 다음 장면이 겹쳐 떠오르므로, 시간이 흘렀거나 같은 주제의 다음 단계로 넘어간다는 뜻을 부드럽게 전합니다. 장면 사이에 공간적 관계가 없을 때 쓰는 기본 전환입니다.

## 언제 쓰나
- 같은 주제의 단계를 차례로 보여줄 때 (수동 배포 → CI → CD, v1 → v2 → v3)
- 레이아웃이 완전히 다른 두 장면을 잇되, 카메라 이동으로 설명할 공간 관계가 없을 때
- 시간 경과를 암시할 때. `blur: true`로 길게 흐리면 "오래 지났다"는 느낌이 강해집니다.
- 어떤 전환을 써야 할지 모를 때. 가장 중립적인 전환입니다.

## 피할 때
- 두 장면에 같은 모양·같은 위치의 요소가 있을 때. 그때는 match-cut이 관계를 더 정확히 보여줍니다.
- 한 다이어그램 안에서 상태만 바뀔 때. 디졸브하면 "다른 장면"처럼 보여 오해를 부릅니다. 요소 단위 tween이나 jump-cut을 쓰세요.
- 연속 4번 넘게 쓸 때. 모든 장면이 똑같이 흐릿하게 넘어가면 리듬이 사라집니다. 중간 하나는 컷(`dur: 0`)으로 끊어 주세요.

## 사용법
장면은 world 안에 `position: absolute; inset: 0`으로 겹쳐 놓은 레이어입니다.
```js
const d = stage.fx("cross-dissolve", {
  from: "#a",     // 사라질 장면 (선택자 또는 요소)
  to: "#b",       // 나타날 장면
  dur: 0.8,       // 초. 0.4 이하는 컷에 가깝고, 1.5 이상은 시간 경과를 암시
  blur: true,     // 블러 디졸브. 숫자를 주면 최대 블러 px (true = 8)
});
stage.tl.stop("CI: 커밋마다 빌드와 테스트가 자동으로 돈다");
// d.start, d.end: 타임라인 초. 다음 장면 요소의 등장을 전환 끝에 맞출 때 씁니다.
```
`to` 장면은 첫 seek부터 opacity 0으로 숨겨지므로 CSS로 따로 숨길 필요가 없습니다. 새 장면 안 요소를 전환이 끝난 뒤 순서대로 띄우려면 `at: "-=0.25"`처럼 전환 끝에 살짝 겹쳐 시작하세요. 모든 장면의 헤더와 본문을 같은 자리에 두면(위 정렬) 디졸브 중에 레이아웃이 겹쳐 보이지 않습니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `from` | 없음 | 사라질 장면. 생략하면 `to`만 페이드인 |
| `to` | 없음 | 나타날 장면. 생략하면 `from`만 페이드아웃 |
| `dur` | `0.8` | 전환 시간(초) |
| `blur` | `false` | `true`면 8px, 숫자면 그 px까지 흐려졌다가 선명해집니다 |
| `ease` | `"inOut"` | `Eidos.ease` 이름 또는 함수 |
| `at` | 타임라인 끝 | 시작 시점 (`"+=0.3"`, `"<+=0.2"` 문법 지원) |

## 변형
- **블러 디졸브:** `blur: true`. 사라지는 장면은 흐려지며 옅어지고, 나타나는 장면은 흐린 상태에서 선명해집니다. 시간이 많이 흐른 장면 사이에 씁니다.
- **페이드인만 / 페이드아웃만:** `from` 또는 `to` 하나만 주면 됩니다. 첫 장면 등장이나 마지막 장면 퇴장에 씁니다.
- **컷:** `dur: 0`. 전환 없이 바로 바뀝니다. 리듬을 끊고 싶을 때.
- **J컷 / L컷 (예정):** 다음 장면 자막을 전환보다 먼저 띄우는 `lead`, 이전 장면 자막을 전환 뒤까지 남기는 `trail` 옵션.

## reduced-motion
정지 지점 사이를 즉시 이동하므로 디졸브 과정은 보이지 않고 장면이 바로 바뀝니다. `blur`는 런타임이 자동으로 끄고(`filter: none`), 화면 전체가 200ms 동안 옅게 페이드됩니다.

## 같이 쓰기 좋은 기법
stagger-reveal(전환 뒤 새 장면 요소를 순서대로 띄우기), establishing-shot(새 장면이 뜬 뒤 전체 보여주기), match-cut(대응 요소가 있는 장면 사이에는 이쪽이 더 정확)
