# 휩팬 (Whip Pan)

## 전달하는 의미
**바로 옆에 있는 같은 급의 다른 것.** 카메라가 빠르게 옆으로 휙 돌아가며 화면이 이동 방향으로 번지고, 곧바로 옆 장면에 멈춥니다. 공간적으로 나란히 놓인 대상 사이를 이동한다는 느낌이라 "같은 층위의 이웃"이라는 관계를 전합니다.

**장면 관계:** 나란한 다른 개념으로 옆 이동. 스토리보드 경계 표에서 두 장면이 같은 레벨의 이웃(서비스 A → 서비스 B)일 때 `via: "whip-pan"`을 씁니다.

## 언제 쓰나
- 같은 레벨의 서비스, 모듈, 팀 사이를 차례로 훑을 때
- 이벤트나 요청이 옆 시스템으로 넘어가는 흐름을 따라갈 때
- 빠른 리듬이 필요할 때. 0.5초 남짓이라 컷만큼 빠르면서도 공간감이 남습니다.

## 피할 때
- 위계가 다른 장면 사이(전체 → 부분). 그때는 `camera`가 정확합니다.
- 대안끼리 비교할 때. 옆에 "있다"는 공간 관계가 없으면 wipe가 낫습니다.
- 글이 많은 장면을 오가며 반복할 때. 번지는 동안은 읽을 수 없으므로 연속 3번까지만 씁니다.

## 사용법
```js
s.scene("order", { el: "#a" });
// ...
s.scene("payment", { el: "#b", via: "whip-pan", with: { dir: "right" }, reason: "나란한 이웃 서비스로 옆 이동" });
```
`dir`은 카메라가 휙 도는 방향, 즉 다음 장면이 놓인 쪽입니다. `right`면 앞 장면은 왼쪽으로 빠져나가고 다음 장면이 오른쪽에서 들어옵니다. 이동 거리는 `stage.onLayout`에서 world 너비(세로면 높이)에 `gap`을 더해 잽니다. 블러는 world 바로 뒤에 둔 SVG `feGaussianBlur` 필터로 이동 축 한쪽만(`stdDeviation="x 0"`) 걸고, 속도에 비례해 가운데에서 가장 강합니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `from` / `to` | 런타임이 채움 | 나가는 장면 / 들어오는 장면 |
| `dir` | `"right"` | `right`, `left`, `down`, `up`. 다른 값은 오류 |
| `blur` | `28` | 방향 블러 최대 px. `false`면 블러 없이 이동만 |
| `gap` | `48` | 두 장면 사이 간격(px) |
| `dur` | `0.55` | 전환 시간(초). 0.4~0.7이 휩팬답습니다 |
| `ease` | `"inOut"` | 위치 이징. 가운데가 가장 빠릅니다 |
| `at` | 타임라인 끝 | 시작 시점 |

## 변형
- **가로 휩팬:** `dir: "right"`/`"left"`. 이웃 시스템 사이.
- **세로 휩팬:** `dir: "down"`/`"up"`. 같은 목록의 위아래 항목 사이. 블러도 세로로만 걸립니다.
- **블러 없는 휩팬:** `blur: false`. 성능이 낮은 기기나 글이 많은 장면.

## reduced-motion
이동과 블러를 모두 끄고 제자리에서 두 장면을 교차 페이드합니다(블러 필터 자체를 만들지 않음). 스톱 사이 이동은 즉시 처리되고 화면 전체가 200ms 동안 옅게 페이드됩니다.

## 같이 쓰기 좋은 기법
cross-cutting(두 흐름을 번갈아 보여줄 때), stagger-reveal(도착한 장면 요소 띄우기), wipe(공간 관계 없는 대안 비교일 때의 대안)
