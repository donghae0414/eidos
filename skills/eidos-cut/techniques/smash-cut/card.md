# 스매시 컷 (Smash Cut)

## 전달하는 의미
**예상과 정반대다.** 예고 없이 0초로 잘라 대비가 큰 장면을 던집니다. 화면 색이 한순간 뒤집히거나 큰 숫자 하나가 화면을 채우면서 "기대 vs 실제", "반전", "충격적인 수치"를 몸으로 느끼게 합니다.

**장면 관계:** 대비, 반전, 폭로. 스토리보드 경계 표에서 다음 장면이 앞 장면의 기대를 뒤집을 때 `via: "smash-cut"`을 씁니다.

## 언제 쓰나
- 로컬 12ms → 프로덕션 4.8초 같은 수치 반전
- "모두가 이렇게 생각한다" 다음에 "실제로는"을 보여줄 때
- 장애, 보안 사고처럼 분위기가 확 바뀌는 순간

## 피할 때
- 두 장면이 이어지는 단계일 때. 충격 효과가 과장으로 읽힙니다.
- 한 작품에서 3번 이상. 두 번까지만 씁니다. 세 번째부터는 아무도 놀라지 않습니다.
- 반전할 내용이 숫자나 짧은 문장 하나로 요약되지 않을 때 `slam`을 쓰지 마세요.

## 사용법
```js
s.scene("local", { el: "#a" });
// ...
s.scene("prod", { el: "#b", via: "smash-cut", with: { slam: "4,812ms" }, reason: "예상과 정반대인 수치" });
s.scene("fixed", { el: "#c", via: "smash-cut" }); // 반전 플래시만
```
장면 교체는 항상 0초입니다. `dur`은 교체 뒤 플래시나 슬램 카드가 남는 시간입니다. 반전 플래시는 world 바로 뒤에 흰색 `mix-blend-mode: difference` 레이어를 두어 화면의 모든 색을 뒤집었다가 옅어지게 합니다.

## 파라미터
| 이름 | 기본값 | 설명 |
|---|---|---|
| `from` / `to` | 런타임이 채움 | 나가는 장면 / 들어오는 장면 |
| `flash` | `"invert"` | `"invert"`(색 반전), `"contrast"`(새 장면 대비·채도를 올렸다 내림), `false`(순수 컷). 다른 값은 오류 |
| `slam` | 없음 | 문자열을 주면 반전 색 판 위에 아주 큰 글자로 먼저 던지고 새 장면으로 넘어갑니다. 이때 flash는 쓰지 않습니다 |
| `dur` | 플래시 `0.45`, 슬램 `1.1` | 플래시/슬램이 남는 시간(초) |
| `at` | 타임라인 끝 | 컷 시점 |

## 변형
- **반전 플래시:** 기본값. 짧고 강합니다.
- **대비 플래시:** `flash: "contrast"`. 색이 확 진해졌다가 돌아옵니다. 반전보다 덜 공격적입니다.
- **슬램 타이포:** `slam: "4,812ms"`. 핵심 수치를 화면 가득 보여준 뒤 설명 장면으로 들어갑니다.
- **순수 컷:** `flash: false`. via `cut`과 같지만 카드와 스토리보드에 "반전"이라는 의도가 남습니다.

## reduced-motion
반전 플래시, 대비 플래시, 슬램 카드를 모두 끄고 0초 컷만 남깁니다(깜빡임은 광과민 위험이 있음). 스톱 이동 시 런타임이 화면 전체를 200ms 동안 옅게 페이드합니다.

## 같이 쓰기 좋은 기법
