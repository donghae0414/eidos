장애 대응 · 3 / 3 · 원인

원인: 외부 PG 호출이 커넥션을 쥔 채 기다린다

고치기 전
@Transactional
fun pay(req) {
  repo.save(order)
  pg.charge(req)   // 3초, 커넥션 점유
}
고친 뒤
fun pay(req) {
  val r = pg.charge(req)  // 트랜잭션 밖
  tx { repo.save(order, r) }
}
  • 커넥션 점유 시간 3,000ms → 40ms
  • 풀 크기를 늘리는 건 증상만 미룬다
